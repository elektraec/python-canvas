# Prueba de Escritorio · B26

Miniapp independiente para practicar trazas manuales de programas Python.

## Incluye
- Variables
- Condicionales
- Ciclo `for`
- Ciclo `while`
- Contadores y acumuladores
- Listas
- 18 ejercicios
- Tablas editables
- Comprobación automática
- Pistas
- Modo paso a paso
- XP y progreso local
- Exportación de progreso
- Diseño responsivo para iframe/Canvas

## Publicación en GitHub Pages

Puedes copiar esta carpeta completa, por ejemplo, dentro de:

`python-canvas/prueba-escritorio/`

y hacer que tu workflow la copie al `dist` igual que hiciste con `laboratorio/`.

Ejemplo de línea adicional en GitHub Actions:

```bash
cp -r prueba-escritorio dist/prueba-escritorio
```

URL esperada:

`https://elektraec.github.io/python-canvas/prueba-escritorio/`
